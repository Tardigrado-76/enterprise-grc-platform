# Security Policy

## Supported Versions
This Enterprise GRC Platform adheres to strict security SLAs.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We maintain a **Zero-Trust** approach and a 24-hour response SLA for critical vulnerabilities (SLSA L3+ compliant). 

To report a vulnerability, please do NOT open a public issue. Send an email to the security team or use the internal CISO reporting pipeline.
All reports will be cryptographically verified before triage.
